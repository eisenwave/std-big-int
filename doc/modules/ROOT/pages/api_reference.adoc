[#api_reference]
= API Reference
:idprefix: api_ref_

[#api_namespaces]
== Namespaces

[cols="1,2", options="header"]
|===
| Namespace | Description
| `beman::big_int` | Contains all components of the library *except* literals and polymorphic memory resource support
| `beman::big_int::literals` | User-defined literals
| `beman::big_int::pmr` | Types with `std::pmr` support
|===

[#api_types]
== Types

[cols="1,2", options="header"]
|===
| Type | Description
| xref:big_int_type.adoc#big_int_type_unit_multi_t[`uint_multiprecision_t`] | The limb type of a `big_int`
| xref:big_int_type.adoc#big_int_type_basic_big_int[`basic_big_int`] | The template of a big integer type. Analogous to `std::basic_string`
| xref:big_int_type.adoc#big_int_type_using_big_int[`big_int`] | A big integer type using default small value optimizations and allocator
|===

[#api_functions]
== Functions

=== <charconv>

[cols="1,2", options="header"]
|===
| Function | Description
| xref:charconv.adoc#charconv_to_chars[`to_chars`] | Writes the textual representation of a `basic_big_int` into a character buffer
| xref:charconv.adoc#charconv_from_chars[`from_chars`] | Parses a `basic_big_int` from its textual representation
|===

=== String conversions

[cols="1,2", options="header"]
|===
| Function | Description
| xref:string.adoc#string_to_string[`to_string`] | Returns a `std::string` holding the textual representation of a `basic_big_int`
| xref:string.adoc#string_to_wstring[`to_wstring`] | Returns a `std::wstring` holding the textual representation of a `basic_big_int`
|===
